# Hajime One-Tap Roblox Script

Hajime One-Tap is a mobile-friendly Roblox script with a black-and-red one-tap control center for local training controls, settings, GUI customization, performance optimization, cooldown display, and match information. It uses touch-friendly buttons, smooth interface animations, and LocalScript functionality for supported Roblox experiences and permitted Delta environments.

## Install

1. Open the Roblox Studio place where you want to use the script.
2. Create a `LocalScript` under `StarterPlayer > StarterPlayerScripts`.
3. Copy the contents of `HajimeUltimateOneTap.client.lua` into the LocalScript.
4. Test the experience in Play mode.
5. For Delta or another supported environment, use the script only where local scripts and the experience rules permit it.

## Use

1. Press the red `HU` launcher button to open or close the control center.
2. Use the Training tab to start a local training session, reset the session, and view the session timer.
3. Use the Settings tab to enable Performance Mode, Touch Haptics, or Auto Open.
4. Use the Customize tab to switch between Compact Layout and Comfort Layout.
5. Select Move Launcher, then drag the `HU` button to reposition it.
6. Use the Performance tab to disable or restore local particle emitters, trails, and post-processing effects.
7. Open the Match tab to view the current place name, online player count, and local cooldown display.
8. Close the control center with the `X` button.
